# המורה שלי — AI-teacher

אפליקציית לימוד מבוססת AI שרצה כולה מקומית באמצעות [Ollama](https://ollama.com). ההפצה היא קובץ **התקנה** (`MoreAI-Setup.exe`) שמתקין תוכנה אמיתית על המחשב, בדיוק כמו כל תוכנה אחרת:

1. מריצים את `MoreAI-Setup.exe` פעם אחת — הוא רק מעתיק את התוכנה ל-`%LOCALAPPDATA%\MoreAI` ויוצר קיצור דרך בתפריט התחל ובשולחן העבודה בשם **"AI Teacher"**. אין הורדות, אין הרשאות מיוחדות, ואין פתיחה אוטומטית של שום דבר. (השם באנגלית דווקא: יש מגבלה ב-COM הישן של Windows‏ (`WScript.Shell`) שגורמת ליצירת קיצור דרך עם שם בעברית להיכשל בשקט - זו הסיבה היחידה, כל שאר האפליקציה בעברית.)
2. מכאן ואילך פותחים את **"AI Teacher"** מתפריט התחל בכל פעם שרוצים ללמוד, בדיוק כמו כל תוכנה מותקנת - הממשק עצמו (וה-title של החלון) בעברית מלאה.
3. בפעם הראשונה שפותחים אותה, נפתח חלון קטן עם מסך טעינה — בלי חלון קונסולה — ומופיע אישור הרשאת מנהל (UAC); אחריו הכול אוטומטי: בודק אם Ollama מותקן, ואם לא מוריד ומתקין אותו בשקט, ומפעיל את השרת.
4. ברגע שהשרת מוכן, נפתח אוטומטית דפדפן עם דף מעוצב (RTL, עברית) שמדבר עם המודל.
5. הדף עצמו בודק אם המודל קיים, ואם לא — מוריד אותו ומציג פס התקדמות חי (אחוזים, MB/GB שהורדו) דרך ה-streaming API של Ollama, לפני שפותח את הצ'אט.
6. חלון "המורה שלי" נשאר פתוח ברקע (עם כפתור "סגור" ליציאה) כדי שהשרת המקומי ימשיך לפעול כל עוד רוצים לדבר עם המורה.

אין שליחת מידע לאינטרנט אחרי ההתקנה הראשונית — הכול רץ על המחשב המקומי.

## מבנה הפרויקט

```
app/
  launcher.py     # התוכנה עצמה - נפתחת מתפריט התחל (Python, ספריית תקן בלבד)
  installer.py    # תוכנת ההתקנה - מעתיקה את launcher.py הקומפל ויוצרת קיצורי דרך
  build_exe.ps1   # בנייה דו-שלבית: MoreAI.exe ואז MoreAI-Setup.exe
  web/
    index.html    # ממשק הצ'אט
    style.css
    app.js        # פנייה ישירה ל-API של Ollama (כולל ה-system prompt)
```

## המודל שנבחר

`gemma2:9b` (כ-5.5GB בכימות ברירת המחדל) — נבחר כי הוא:
- **תחת 8GB** כנדרש.
- חזק בהסבר/הוראה יחסית לגודלו (feedback חיובי עקבי על יכולות reasoning והסברה).
- תומך בעברית בסבירות טובה הודות לקורפוס האימון הרב-לשוני הרחב של Gemma 2.

לשינוי מודל: עדכנו את הקבוע `MODEL` ב-`web/app.js` (ההורדה וההרצה מנוהלות כולן מהדפדפן, מול ה-API של Ollama).

## הרצה בפיתוח (בלי לבנות EXE)

```powershell
cd app
python launcher.py
```

## בניית ה-EXE

דורש Python 3.9+ ו-pip מותקנים על מכונת הבנייה (לא אצל המשתמש הסופי).

```powershell
cd app
./build_exe.ps1
```

התוצאה: `app/dist/MoreAI-Setup.exe` — זה קובץ ההפצה למשתמש הסופי (מטמיע בתוכו את `MoreAI.exe`). מריצים אותו פעם אחת בלבד, גם בלי Python מותקן על המחשב שמריץ אותו.

## הערות

- `MoreAI-Setup.exe` (ההתקנה) לא דורש הרשאת מנהל — הוא רק מעתיק קובץ ויוצר קיצורי דרך ב-`%APPDATA%` וב-`%LOCALAPPDATA%` של המשתמש הנוכחי, ולא פותח שום דבר בסיום.
- `MoreAI.exe` (התוכנה עצמה, זו שמותקנת ונפתחת מתפריט התחל) נבנה עם `--uac-admin` (מבקש הרשאת מנהל אוטומטית בפעם הראשונה שפותחים אותה) ו-`--windowed` (בלי חלון קונסולה) — כל הלוגים/שגיאות, אם יש, נכתבים ל-`%TEMP%\moreai_error.log` במקום להיות מודפסים.
- ההתקנה השקטה של Ollama משתמשת בדגלי Inno Setup (`/VERYSILENT`); אם גרסת ההתקנה תשתנה בעתיד וההתקנה השקטה תיכשל, החלון יציג הודעת שגיאה.
- שרת ה-Ollama מופעל עם `OLLAMA_ORIGINS=*` כדי לאפשר לדף המקומי (`http://127.0.0.1:8765`) לקרוא ל-API בלי חסימת CORS.
- אין שרת backend נפרד — הדפדפן פונה ישירות ל-`http://127.0.0.1:11434` של Ollama.
