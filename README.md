# המורה שלי — AI-teacher

אפליקציית לימוד מבוססת AI שרצה כולה מקומית באמצעות [Ollama](https://ollama.com). קובץ EXE יחיד:
1. בודק אם Ollama מותקן, ואם לא — מוריד ומתקין אותו, ומפעיל את השרת.
2. פותח מיד דף אינטרנט מעוצב (RTL, עברית) שמדבר עם המודל ועוזר ללמוד.
3. הדף עצמו בודק אם המודל קיים, ואם לא — מוריד אותו ומציג פס התקדמות חי (אחוזים, MB/GB שהורדו) דרך ה-streaming API של Ollama, לפני שפותח את הצ'אט.

אין שליחת מידע לאינטרנט אחרי ההתקנה הראשונית — הכול רץ על המחשב המקומי.

## מבנה הפרויקט

```
app/
  launcher.py     # לוגיקת ההתקנה/הפעלה (Python, ספריית תקן בלבד)
  build_exe.ps1   # בנייה ל-EXE יחיד עם PyInstaller
  web/
    index.html    # ממשק הצ'אט
    style.css
    app.js        # פנייה ישירה ל-API של Ollama (כולל ה-system prompt)
```

## המודל שנבחר

`gemma2:9b` (כ-5.5GB בכימות ברירת המחדל) — נבחר כי הוא:
- **תחת 8GB** כנדרש.
- חזק בהסבר/הוראה יחסית לגודלו (feedback חיובי עקבי על יכולות reasoning והסברה).
- תומך בעברית בסבירות טובה הודות לקורפוס האימון הרב-לשוני הרחב של Gemma 2.

לשינוי מודל: עדכנו את הקבוע `MODEL` ב-`web/app.js` (ההורדה וההרצה מנוהלות כולן מהדפדפן, מול ה-API של Ollama).

## הרצה בפיתוח (בלי לבנות EXE)

```powershell
cd app
python launcher.py
```

## בניית ה-EXE

דורש Python 3.9+ ו-pip מותקנים על מכונת הבנייה (לא אצל המשתמש הסופי).

```powershell
cd app
./build_exe.ps1
```

התוצאה: `app/dist/MoreAI.exe` — קובץ יחיד שניתן להעביר ולהריץ על כל מחשב Windows, גם בלי Python מותקן.

## הערות

- ההתקנה השקטה של Ollama משתמשת בדגלי Inno Setup (`/VERYSILENT`); אם גרסת ההתקנה תשתנה בעתיד וההתקנה השקטה תיכשל, תוצג למשתמש חלונית התקנה רגילה להשלמה ידנית.
- שרת ה-Ollama מופעל עם `OLLAMA_ORIGINS=*` כדי לאפשר לדף המקומי (`http://127.0.0.1:8765`) לקרוא ל-API בלי חסימת CORS.
- אין שרת backend נפרד — הדפדפן פונה ישירות ל-`http://127.0.0.1:11434` של Ollama.
